# HindustaniSangeet

Static 4-page website designed for GitHub Pages.

## Pages
- index.html — Home
- about.html — About + gallery + YouTube video
- classes.html — Classes
- register.html — Google Form registration/contact

## Before publishing
1. Replace the SVG placeholder images in `images/` with your own JPG/PNG photos, keeping the filenames or updating the HTML.
2. In `about.html`, replace `YOUR_VIDEO_ID` with your YouTube video ID.
3. In `register.html`, replace `YOUR_GOOGLE_FORM_ID` with the embed URL from your Google Form.
4. Edit school wording, class details, and contact information to match your actual program.
5. Push the folder to GitHub and enable GitHub Pages from repository Settings → Pages.
